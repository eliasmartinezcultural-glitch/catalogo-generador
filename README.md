# Catalogo Express

Fábrica de catálogos para WhatsApp de Ocarina.

## Base profesional
- Una sola fuente de verdad para el estado.
- Vista previa derivada del estado.
- Mobile first.
- GitHub Pages, sin backend.
- Persistencia local para no perder borradores.
- Base preparada para presets, imágenes, publicación y carrito.

## V1 funcional
Constructor, presets, productos, vista previa en tiempo real, persistencia local y enlace de WhatsApp.
